# Fontify Anti Slop delivery

Applied the Anti Slop plugin in during mode. Direction comes from Fontify's existing Outfit typography, lavender M3E tonal palette, expressive selected shapes, and browser-extension workflow. ENERGY 2 / RHYTHM 2 / MOTION 1.

## Changes and reasons

- Retain Outfit, the existing icon, and M3E components: these are Fontify's established identity.
- Retain lavender as the primary accent: it marks selected controls and the working font specimen.
- Remove repeated slogan eyebrows and decorative hero blobs: settings titles should identify the task, and the specimen should demonstrate the fonts.
- Keep the typography page's existing pun: it gives Fontify a recognisable voice without obscuring the functional navigation labels.
- Replace vague library, override, upload, and preference copy with action names: users can identify where to change a setting.
- Use a pangram, numerals, bold, and italic in the specimen: users can compare actual letterforms and styles.
- Apply selected families to the profile-card glyphs: those samples previously showed the interface font rather than the selected profile.
- Place preview controls beside the specimen in reading order: changes have an immediate, nearby result.
- Put popup site actions and All settings above the specimen: quick controls stay reachable before the longer preview.
- Use 18px profile-card corners, larger grouping surfaces, and the existing asymmetric specimen/selected-navigation shapes: radius communicates hierarchy while preserving M3E character.
- Use plain empty-state text rather than repeated decorative icons and dashed cards: the next useful action is easier to read.
- Wrap navigation at narrow widths and constrain grid tracks: settings remain accessible without horizontal page scrolling.
- Give buttons, filters, icons, and the size slider at least 44px target height: the compact extension remains usable by touch.
- Keep native control borders at the outline token and remove text opacity reductions: boundaries and text remain distinguishable in both themes.
- Make the main shell inert while dialogs are open, focus the editor, and restore its trigger after closing: keyboard users stay in the task and return to their place.
- Resolve the system theme before choosing the corner toggle's action: clicking it now switches to the opposite visible theme.
- Add a persistent startup error and retry action: a failed catalogue load no longer leaves a loading screen with a disappearing toast.
- Ignore outdated asynchronous preview results and clear recovered errors: a slow previous selection cannot overwrite a later specimen.

No new visual assets, navigation destinations, dependencies, or settings-schema changes.

- Every settings section checked in light and dark at 1240, 768, 390, and 320px. Document overflow, rendered text contrast using the WCAG luminance formula, and control target height assertions passed. The popup also passed light/dark checks at 320px.
- Screenshots recorded for all 40 settings/theme/width combinations and the popup. Desktop typography, narrow typography/preferences, and popup captures were visually inspected.
- Keyboard tests verify initial editor focus, nested picker/editor Escape handling, restored trigger focus, and focus remaining in the popup dialog while tabbing. Source review confirms native focus outlines and M3E strong-focus remain enabled.
- Firefox interactive behaviour and physical mobile keyboards were not tested. Firefox validation is build/lint only. The builds remain unsigned development packages.

- Style weights render their defaults; override weight changes persist after Save changes.
- Global enable switches pause and restore page typography, including original inline priorities. Code replacement changes fixed-width text while protecting icons.
- Preview text updates the specimen; size changes update the specimen and its px output.
- Picker search filters results; all category filters change their selected state; Show more expands the list; saving and unsaving a favourite changes Saved results; unmatched searches show an empty state.
- Picker Close, Done, and Escape close it. Closing a nested picker returns focus inside the override editor. Closing the editor returns focus to Edit.
- Each navigation button opens its real section; narrow navigation wraps visibly.
- Upload accepts the bundled TTF; Use applies it; Remove confirms deletion and restores the empty library state.
- Exception type selection works; an invalid hostname shows validation; selector exceptions preserve page text; font exceptions can be added and removed.
- A context-menu-equivalent block request opens the composer; Save override persists across reloads; Edit, Save changes, Cancel, and Remove work.
- Theme controls change light/dark mode. System light and system dark each make the corner button switch to the opposite visible mode.
- Download permission toggles; Clear cache confirms completion while keeping custom fonts.
- Export produces a JSON backup; Import restores it after confirmation; Reset clears settings while retaining uploaded fonts.
- Popup Pause here and Resume here update the site's exception. All settings opens the options page.
- Failed catalogue startup shows a persistent error; Try again recovers the interface.
- Runtime page-error collection is empty. Existing external Source & feedback and M3E links retain their real destinations and explicit new-tab arrows; no new links were introduced.
