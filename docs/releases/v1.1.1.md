# Fontify 1.1.1

Fontify now shows your font choices throughout its own interface, with a wider popup and clearer Material 3 Expressive navigation.

## Changes

- Apply the selected default or sans-serif font throughout settings and the popup. Bold and italic text use their saved profiles; fonts that cannot load fall back to Outfit.
- Widen the native toolbar popup to 520px and keep site pause/resume and All settings above the preview. Fix the viewport-relative sizing that could shrink the popup.
- Enlarge the sidebar and use thick Material Symbols Rounded with outlined and filled selection states.
- Add short selection and press shape changes, icon transitions, and a picker entrance. Respect reduced-motion preferences.
- Replace vague settings copy with clear action names, and use a pangram, numerals, bold, and italic text in the preview. Profile-card glyphs now show their selected fonts.
- Improve narrow layouts, touch targets, and text contrast in light and dark themes.
- Keep keyboard focus inside dialogs and restore it to the opening control after closing. Correct the theme button when following the system theme.
- Show a persistent retry action if startup fails, and prevent older font requests from overwriting newer previews.

Existing settings, uploaded fonts, exceptions, and overrides remain compatible. No new extension permissions or runtime dependencies.

## Downloads

Chrome: extract the Chrome ZIP and load its folder from chrome://extensions. The CRX3 is signed with the configured repository key; it is not a Chrome Web Store signature.

Firefox: use the signed XPI from this release when available. The explicitly named unsigned XPI is for temporary development installation. Signing uses Mozilla's unlisted channel; this release does not create a public Mozilla Add-ons listing.

The source ZIP contains the human-readable application, tests, locked dependencies, and build instructions. Signing keys are excluded from downloads.

## Validation

Eight unit tests, Chrome and Firefox builds, Firefox lint, and the real Chromium extension integration suite. The suite covers font propagation into the extension interface, uploads, exceptions, overrides, pause/restoration, backups, reset, keyboard focus, theme controls, startup recovery, local symbols, reduced motion, and native popup sizing.

Layout, text contrast, and control targets are checked at 1240, 768, 390, and 320px in both themes. Firefox lint retains the previously documented Lit dependency warning; Firefox interactive behaviour and physical mobile keyboards were not tested.
